# 魔法家族首页与产品切换

## 用户与目标
- 面向模型服务使用者、大学生与创作者：保留原品牌官网，先了解子产品；登录默认进入魔法 API 控制台，再从顶部切换工具。
- 不另建账号系统，不更改套餐、计费、认证或权限；生产不自动发布。

## 已实现产品边界
- 魔法 API：原本站控制台、密钥、用量与账户。
- 魔法配方：独立页，工作／大学／创作模板，用户主动选择或手动配置模型；Key 导入必须显式授权。
- 魔法工坊：独立公开创作资源首版；图片是原创示例，视频运镜为二维示意，不直接生成、不自动安装 Skill，定时任务关闭。
- SynaRoute：桌面工具，在密钥页主动导入 API 配置；并非账号单点登录。

## 入口规则
- 原 BrandPanel 的首屏、文案与狮冠 M 原样复用，下面介绍产品。后台自定义 home_content 仍优先。
- 四款产品在同一展台中预览，默认配方；预览标签不产生登录、跳转或模型请求，只有面板中的进入动作才导航。已知产品锚点选择对应面板，未知锚点不构造外部地址。
- 匿名产品点击先登录进入 `/dashboard?product=<已知标识>`，不自动跳转外部或授权；控制台提供继续打开按钮。普通登录仍 `/dashboard`。
- 独立产品新窗口打开；生产没有配置发布地址则禁用。URL 不携带登录令牌或密钥。
- 没有通用跨产品 SSO 或统一退出；真实账号授权闭环仍由用户验收。
