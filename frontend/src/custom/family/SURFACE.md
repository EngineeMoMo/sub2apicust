# 首页扩展与控制台胶囊切换

## 用户确认
2026-09-30 用户否决账户摘要＋目录主首页。原话要求“品牌首页还是之前的，下面有附属品的介绍和链接……登陆后进api控制台，控制台里面可以切换其它的子品牌”，以截图中央胶囊导航为布局参考，“也要做的炫酷”。不能复制截图品牌、余额或假数据。

## 方向契约
- THESIS：官网介绍家族，API 控制台是登录后的操作中心。
- OWN-WORLD：继承狮冠 M、雾钛青与默认深色，SynaRoute 保留紫色；不重新定义母品牌。
- STORY：原品牌首屏 → 四款产品的互动展台 → 用户主动登录／打开 → 可展开的会话与授权边界。
- FIRST VIEWPORT：原 BrandPanel 双栏、原标志与三条原 CTA 不改；账户摘要不再出现在首屏。
- FORM：首页是 Persuade，四款产品共用一座展台，不再排成长篇产品卡片。四个有独立标识的标签是预览入口，当前面板才提供明确的登录／打开动作；默认大学配方，已知产品锚点优先。控制台是 Operate，宽屏居中的紧凑产品坞继续保留四个直接入口，不遮挡账户功能。
- SIGNATURE：产品标签移动细轨与预览面板一次性裁切／平移衔接；配方是一张雾青方法单，工坊为旋转叠放的原创图例，API为原M接入轨道，SynaRoute为真实配置关系示意。图例不充当模型实测，动画默认内容可见，reduced-motion关闭过渡。标签支持左右键／Home／End及循环焦点，手机为两列入口。
