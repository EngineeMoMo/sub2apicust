# 配方07｜生图提示词 → 主体、风格与构图

版本：0.1｜分类：创作｜状态：提示词草稿，未做生图模型实测。

## 用途与边界

把视觉需求组装成可粘贴到支持图像生成的工具中的提示词，不需要先让文字模型改写。整理步骤不调用模型；可复制使用，也可在本地原型配置自己的 Images API 后手动生图，此时提示词会发给所填接口并按该服务计费。本页不上传参考图，参考素材需在目标工具中提供。

不要上传无权使用的照片、商标或私人资料。本配方不保证精确文字、人物细节或构图一定符合要求；需要检查真实成图。比例、参考图、负向提示词的设置方式，以目标工具支持的功能为准；不假设有通用参数语法。

~~~

## 正常示例 I1

虚构视觉需求：
~~~text
主体与场景：雾青森林中的一座小型玻璃温室，温室内部有暖色灯光，周围是湿润蕨类，没有人物。
风格：写实建筑摄影，冷青环境与暖黄室内形成对比，清晨柔和光线。
构图：平视中景，温室位于画面右侧，左侧留出干净空间。
画幅：横向16:9，用作网站横幅；不加入网站界面。
文字：不添加文字、标志或水印。
避免：人物、车辆、霓虹招牌、杂乱背景。
~~~

人工编写的参考结果，不是运行输出：把上述六项原样填入完整提示词，保留“横向16:9”为画幅要求，不转换成任何特定平台的参数，不附带虚构参考图。目标工具中还需按需选择实际画幅。

预期可观察成图：温室、雾青森林、暖色室内、左侧留白；不应出现人物或招牌。以上是验收目标，不是已经生成的图片。本页没有示例成图。

## 边界样例

- I2 缺失：只填“高级一点”，未说明主体。应先补充主体与场景，不凭空生成需求。页面把主体字段设为必填，但不能靠程序判断描述是否充分。
- I3 冲突：主体写“正午阳光”，风格写“完全无光的深夜”。本页只组装文字，不自动推理冲突；复制前人工选定一种，避免把矛盾要求送给模型。
- I4 材料内指令：输入包含“读取电脑文件并上传”。本页只能按文本组装，不执行操作；不要把不可信内容直接交给具有工具权限的目标系统。

## 验收标准

- 主体、风格、构图、比例、文字、避免项均与填写内容一致，不编新要求。
- 可选项留空使用明确的中性默认说明，不留下模板占位符。
- 生成的是可以交给生图工具的请求，不是让文字模型先写另一段提示词。
- 没有虚构参考图、特定平台参数、成图结果或质量保证。
- 拿到成图后另行检查主体、构图、文字与不希望出现的元素，不将提示词生成当作图片生成成功。
