# 魔法配方本地原型

## 产品事实

母品牌魔法家族，工作配方3份，大学配方3份，创作配方2份（生图、视频）；学生系列仅大学。素材与内容沿用同目录既有样品。所有配方仍为待模型验证的草稿。

## 本轮实施边界

采用独立静态HTML/CSS/JavaScript原型作为可逆的实现选择，不代表用户已经确认最终技术栈。页面可搜索、筛选、填材料、整理和复制完整提示词。用户明确要求后新增自己的模型设置：文字支持兼容 Chat Completions／Responses、生图支持 Images API；只在手动运行或追问时由浏览器直接请求所填接口。视频仍复制到目标工具。另按用户要求复用魔法 API 登录，选择本人已有密钥、分组和模型并明确授权导入；原账号密码与登录令牌不进入配方页，不建立独立账号系统。

用户输入仅保存在本页内存。刷新或关闭会丢失；清空及示例覆盖需确认。分享或收藏只使用配方标识，不把材料写进URL。下载提示词会在用户设备生成明文文件，操作前应提醒脱敏。

文字与生图连接分别保留在本页内存，密钥默认隐藏、不持久化；应用配置不发送请求。运行会发送完整提示词，追问会携带当前对话，费用与数据处理以用户接口为准。修改材料、切换配方或应用当前连接清除对话并停止等待；不自动重试或执行返回内容。远程 HTTPS，本机 localhost／127.0.0.1／[::1] 可 HTTP，服务需允许浏览器跨域。

## 未确认

视觉验收、最终技术栈、正式部署位置、实际服务兼容性和模型效果未确认。模型接口只使用本机模拟服务验证，不等于真实付费服务已经接通。登录选择的来源授权、密钥过滤、目录读取与配对回传已有自动测试；本机匿名登录跳转保留目标经浏览器验证，真实登录后导入闭环未实测。原站新增选择页尚未发布到8080镜像或生产，需要两端更新、明确允许配方来源及API CORS后再验收。SynaRoute与生产不变。
