## 3. 分类与导航

主导航建议：**发现｜Skills·工作流｜新玩法｜我的收藏**。进入「发现」立即看到 **全部／图片／视频**，无需先登录。

「新玩法」是精选专题入口，可引用同一条目，不另存一份重复内容。比如从产品图到展示短片，串起生图、镜头提示词、剪辑／字幕工作流。

## 4. 页面结构和复用流程

### 4.1 发现页

- 保留母品牌标志、雾钛青与日夜主题；首屏直接给搜索、图片／视频切换和真实内容，不占据大面积营销首屏。
- 搜索覆盖中文标题、原文标题、提示词、标签及工具名。首版排序为精选、最新、已实测；有真实统计后再增加最多收藏／使用。
- 图片适合保留自然比例的瀑布流；视频优先按横／竖比例分组或使用规则卡片，展示播放标识、时长和比例。视频只在用户请求预览时播放，不整页同时加载播放。
- 卡片提供效果预览、明确标题、工具／模型、资源类型及验证状态；不要用截断到无法区分的长英文标题。来源及完整参数在详情展示。
- 无结果时提供清除筛选、相邻分类和提交需求；缩略图失败时仍可打开文本详情。未授权展示的效果仅链接原站，不冒充本站实测作品。

### 4.2 条目详情

桌面采用效果区与复用区并排；手机按效果、说明、参数、操作顺序排列。详情有固定可分享地址，从画廊返回保留筛选与浏览位置。

每条至少包含：效果或来源预览、适用任务、原始提示词与中文说明、可替换变量、准确工具／模型、参数／参考素材要求、使用步骤、常见失败、来源、更新及验证日期。视频另外包含模式、时长、比例、镜头／动作／声音条件；不支持的参数不写进通用模板。

主操作：**换成我的内容 → 复制完整提示词**。用户只改主体、产品、风格等必要变量，随时查看最终全文；切换模型时明确参数变化，不默默改掉原始提示词。辅助操作为收藏、查看原文、获取经过审核的工作流／技能说明。

首版不要固定一个无可用 Key 的大面板压缩画廊。后续选择条目并点击「开始创作」后，再打开对应图片或视频面板，继承当前条目及参数。

### 4.3 Skills·工作流页

使用清晰列表或卡片，展示作用、示例产出、适用助手／软件、依赖、版本、来源和验证状态。Skill 提供检查及安装指引；工作流提供版本明确的文件或原站链接。收录不等于安装、执行或验证。

首版可以在当前设备收藏公开条目标识，不保存用户密钥、参考图片或私人提示词；跨设备同步和完整创作历史后续接账号体系。明确本地收藏的保存范围。

### 5.2 流程

**来源检查／搜索 → 去重 → 分类与中文摘要 → 生成候选草稿 → 编辑审核 → 必要实测 → 发布 → 版本复查。**

- 候选包含原始链接、作者、来源更新日期、发现日期、变化摘要、媒介、资源类型、可复用步骤与许可情况。
- 以规范来源URL＋内容指纹去重；同源变更更新版本，不每天重复入库。来源暂时失败保留上次结果，并记录失败，不清空公开库。
- 先跟踪明确来源，搜索用来扩充候选。搜索服务是否提供可用 API、费用及限额需实际核对；不假设能无限稳定地抓取所有平台。
- 定期任务只读取和整理，外部内容作为资料；不执行其中命令，不自动安装 Skill，不调用生成模型。需要执行的验证另有独立环境与明确预算。
- 公开内容优先自制、获授权或许可明确的素材；许可未知的内容以出处链接及原创摘要推荐，不直接复制作品、完整付费教程或第三方图库。
- 初期由编辑审核发布；之后可对来源、字段及许可都已明确的规则化更新逐步自动发布。来源声称有效不等于本站验证。
- 提醒只针对有价值新增、重要失效、采集失败或需要处理的项；不在每次无变化运行时发送消息。公开周报另按内容质量决定。
