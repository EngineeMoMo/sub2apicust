# 魔法工坊 · 本地首版

魔法家族第四款产品：看图片或镜头效果，替换自己的内容，复制到创作工具使用。2026-09-30用户授权先做产品，**定时任务暂不启用**。

## 打开

在本目录运行 `npm start`，打开 http://127.0.0.1:4179 。服务只监听本机，不占用现有4175／4178／8080产品端口。Node 20以上；运行无第三方依赖，无需构建或配置API Key。

PowerShell：

```powershell
Set-Location D:\ccfile\sub2apicust\product-samples\magic-studio
npm start
```

## 可以使用

- 发现：8条图片、4条视频提示词，关键词／媒介／用途／资源类型筛选和排序。
- 复用：修改变量、中英文模板、复制提示词、下载TXT、复制条目链接、大图预览。
- Skills·工作流：2条Remotion Skill与2条ComfyUI官方模板使用指引，提供真实来源、步骤、条件及安装命令的复制入口。
- 新玩法：4组图片→镜头→工具的三步创作组合，可直接选择对应条目。
- 本机收藏、最近浏览、深浅主题；存储不可用时回退当前页状态。

分享只带条目ID。收藏、最近浏览、主题只存当前浏览器的白名单字段；填写材料不持久化，切换条目时在当前页保留，刷新后恢复示例。下载TXT会包含当前材料，使用前脱敏。

## 真实边界

8张图片由内置image_gen原创制作，8套可替换图片模板尚未在目标工具逐条验证；两者不混为成功证据。视频预览是静态图的二维运镜示意，具有播放／暂停与减少动画偏好，不是模型生成视频。Skill未安装运行，工作流条目是官方模板使用指引，不是假装已验证的工作流JSON。

当前没有生成API、账号集成、自动搜索、采集审核或任何定时任务。页面CSP限制连接为`connect-src 'none'`。未推送、发布、部署生产或更改现有中转站、配方、SynaRoute。

## 文件与验证

- `catalog.mjs`：目录、模板、变量、出处及玩法。新增条目须补验证状态，不能写虚构成功率。
- `core.mjs`：检索、存储白名单、模板替换及导出；`app.mjs`：界面交互。
- `index.html`／`theme.css`：独立页面与雾钛青日夜样式；不接上游主题或业务。
- `serve.mjs`：仅白名单静态文件，拒绝文档与目录读取；未来生产托管另行确认。
- `assets/PROVENANCE.json`：每张原创图精确生成提示词、生成方式及原品牌来源；PNG iTXt和WebP XMP均保留同样来源。PNG保留原图，页面使用压缩WebP及缩略图。
- `PRODUCT.md`／`SURFACE.md`／`DESIGN.md`：产品事实、参考结构与实现规范；`PLAN.md`保留分阶段规划。

`npm test`运行Node测试及jsdom交互回归。jsdom复用本仓frontend已安装的开发依赖，不作为本产品运行依赖。21项定向覆盖组合筛选、存储损坏／禁止、材料保留／恢复／脱敏分享、剪贴板失败回退、深链接、运镜偏好、静态服务边界、类型跳转同步、手机返回保留材料与弹窗名称。

实际浏览器已验证替换后复制、ID链接、TXT落地内容、收藏重开、空搜索恢复、Esc关闭大图、运镜播放暂停。320／390／768／1280／1440／2560宽度未见外层横向溢出。截图及测试日志在`.impeccable/review/`；视频及Skills采用有效实际视口，浏览器工具部分全页导出有布局失真，不把失真文件当验收证据。设计扫描引擎不可用。独立审查首轮为fix，类型筛选／手机返回／弹窗名称三项P2已修复；同一审查者复核评分均resolved、Verdict Pass为ship，仅覆盖这三项修复，详见finish-review.md／finish-verdict.md，不构成目标模型或生产批准。

`prepare-assets.py`仅用于重新压缩已有图片并嵌入来源，需要Pillow；运行页面不需要Python。`verify-assets.py`只读核对25个PNG／WebP的来源，不修改素材。

目标模型的效果与权限、实际视频、真实Skill运行、正式名称／托管域名、首批人群及运营预算仍待确认。自动搜索与调度应另获用户启用授权后实施。
