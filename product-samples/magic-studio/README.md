## 作品与提示词

- 左侧点击图像打开完整作品与提示词并排详情；手机上下排列，图像不裁切。
- 30张图有准确原始提示词，与来源记录逐字对应；此前8张只有摘要记录，明确提示缺失，不编造原始提示词。
- “原始提示词”保留实际发送原文；“复用模板”是另写的可替换版本，不把两者混成模型实测。
- 卡片可直接复制模板或“改成我的”；详情可分别复制原始提示词、当前材料模板，再回右侧修改。切换保留当前页草稿。
- TXT包含当前材料模板、可用原始记录、条件、来源和状态。分享只带条目ID；收藏、历史和主题仅存白名单字段，材料不持久化、不进入链接。
- 自动复制失败时显示手动文本，弹窗内失败文本不会被放到被遮挡的右侧工作区。系统剪贴板与真实TXT落地，本轮未独立实测。

## 运行与部署

本仓默认同一镜像提供主站、配方、工坊；登录后 `/tools/studio` 在API控制台右侧正文打开，独立浏览为 `/studio/`。可选独立拆分接缝仍保留。实际8080与生产状态看根HANDOFF，本轮内容仅源码预览，未重建Docker、提交推送或更新生产。

独立源码预览需要Node20以上：
```powershell
Set-Location D:\ccfile\sub2apicust\product-samples\magic-studio
npm start
```
只监听本机4179，不占用8080；运行时无第三方依赖。主站Vite预览使用4185，需要生成内置产品目录并显式 `--config vite.config.ts`；不要覆盖用户正在填写的旧页面。
